The Cube 🎲

A fully interactive 3D Rubik's Cube built with Three.js. Solve, scramble, track stats, and customize — all in the browser.

Version: 0.99.2

Features

Multiple cube sizes: 2x2x2, 3x3x3, 4x4x4, 5x5x5
Drag & swipe controls — rotate layers by dragging faces, rotate the whole cube by dragging empty space
Momentum-based flipping for natural layer turns
Scramble generation with configurable difficulty
Auto-detect solved state
Save/resume games via localStorage
Live timer and statistics (best/worst time, averages of 5/12/25)
Confetti + "Best Time!" celebration on new records
Customization:

Flip animation types: Swift, Smooth, Bounce
Adjustable camera FOV
5 color schemes: Cube, Erno, Dust, Camo, Rain
Theme editor with HSL sliders (click a face/piece to edit its color)
Getting Started

Download cube.html, cube.css, and cube.js into the same folder.
Open cube.html in a modern browser with WebGL support.
Three.js r95 is loaded from CDN — an internet connection is required on first load.
How to Play

Double-tap / double-click to start.
The cube auto-scrambles.
Drag faces to turn layers; drag the background to rotate the view.
Solve it — your time is recorded automatically.
Use the corner buttons for stats, preferences, back, theme, and reset.
